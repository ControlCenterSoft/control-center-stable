# Control Center 0.6.0 development package

Control Center 0.6.0 starts the Site Autonomy and Network Foundation stage.

Initial parallel workstreams:

- hierarchical Site contracts and delegated boundaries;
- Site state synchronization ownership/conflict rules;
- Network & Security Manager safety contracts;
- explicit Edge Gateway authorization contract for routing/NAT/port-forwarding
  plans: Edge role + approval + capability + distinct WAN/LAN interfaces;
- staged network changes with connectivity validation and rollback;
- network telemetry inputs for Capacity Planner.

The release remains under development until the 0.6 acceptance gates are satisfied. Production network mutation is not enabled by this marker.

The Edge Gateway contract is plan-only and emits stable fail-closed deny codes.
It does not add an execution endpoint, automatic routing, or a production
network mutation path.
