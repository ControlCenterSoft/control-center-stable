# Control Center 0.7.0 development package

Control Center 0.7.0 starts from the qualified 0.6.0 Go product baseline.

## Baseline rules

- Release identity is `0.7.0`.
- Existing Control Center core, Market, node enrollment, domain provider, automation, PXE, lifecycle, inventory, capacity, network-safety and public API guarantees remain cumulative.
- Prepared changes may enter this release only after compatibility checks against the current Go baseline and successful CI qualification.
- No legacy Python implementation is imported into the current product line.
- Empty/no-op branches are not merged solely to create release history.

This file is a development marker. It does not claim that Control Center 0.7.0 feature scope or acceptance is complete and it is not an authorization for an official release.
