# Control Center 0.8.0

Статус: кандидат разработки, не официальный релиз.

Версия 0.8 продолжает Capacity & Placement Advisor после прогнозирования и
what-if анализа 0.7 и добавляет детерминированный рекомендательный выбор узла
для дополнительной нагрузки.

## Placement Advice

`internal/capacity/placement.go` оценивает только здоровые узлы, уже имеющие
требуемую роль. Алгоритм не назначает роль и не изменяет Desired State.

Для каждого кандидата рассчитываются:

- текущая и прогнозная нагрузка после добавления workload;
- безопасный и технический остаток;
- процент безопасного резерва узла;
- существующий резерв по выявленному bottleneck;
- качество исходных данных Capacity Profile.

Кандидат отклоняется, если прогноз превышает безопасную ёмкость, нарушает
технический предел, уже находится за bottleneck-границей, не сохраняет
минимальный резерв либо имеет низкую достоверность исходных данных.

Перед выдачей рекомендации выполняется общая оценка парка через существующий
`BuildAssessment` с заданным числом отказавших узлов. Если общий безопасный
резерв парка недостаточен, конкретный узел не рекомендуется и возвращается
действие `add-role-capacity`.

Допустимые кандидаты сортируются детерминированно: сначала по большему проценту
безопасного резерва, затем по confidence, bottleneck reserve и стабильному ID
узла. Результат имеет воспроизводимый `advice_id`.

Placement Advice остаётся исключительно рекомендательным:

- `advisory_only = true`;
- `production_mutation = false`;
- нет команд провайдера, изменения сети, роли или конфигурации узла;
- низкая достоверность приводит к `collect-evidence`, а не к автоматическому размещению.

Добавлены модульные проверки детерминированного ranking, сохранения отказоустойчивого
резерва, блокировки небезопасного парка и fail-closed поведения при низкой
dостоверности.

Официальный выпуск 0.8.0 допускается только после успешной полной qualification,
точного дополнительного review и release gates.
