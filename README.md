# Control Center 0.27.0 Stable

Control Center — самостоятельная платформа управления инфраструктурой для администраторов. Этот репозиторий является официальным публичным Stable-каналом продукта.

## Текущая стабильная версия

**0.27.0** — текущая стабильная версия.

Основное изменение 0.27.0 — проверяемая модель актуальности успешных изолированных проверок восстановления. Она позволяет отличать свежие доказательства restore drill от устаревших и не принимать исторический статус успешного восстановления как достаточное подтверждение текущей готовности.

Новые recovery-контракты являются только read-only evidence: они не запускают backup/restore, не изменяют инфраструктуру и не предоставляют полномочий на выполнение опасных операций.

## Аутентификация после чистой установки

Чистая установка создаёт локального пользователя `admin` с первоначальным паролем `admin`. При первом успешном входе пароль необходимо обязательно изменить; до смены пароля обычная работа запрещена. Обновление существующей установки сохраняет заданный администратором пароль и не сбрасывает его.
