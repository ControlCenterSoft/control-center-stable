# Control Center 0.27.0 Stable

Control Center — самостоятельная система централизованного управления серверной и пользовательской ИТ-инфраструктурой. Этот репозиторий является официальным каналом стабильных выпусков.

## Текущий стабильный релиз

**0.27.0** — текущий PUBLIC STABLE RELEASE. Release identity подтверждается опубликованным tag `v0.27.0`, release manifest, checksums, qualification evidence и provenance текущего stable-дерева.

Версия 0.27.0 добавляет детерминированную read-only оценку актуальности реально проверенного изолированного восстановления (Restore Drill Freshness) с exact evidence binding и fail-closed revalidation. Предыдущая стабильная версия 0.26.0 ввела permission-gated проверку целостности Audit-цепочки; опубликованные migration-файлы остаются immutable.

## Аутентификация после чистой установки

Чистая установка использует обязательный bootstrap-flow локального администратора с принудительной сменой первоначального пароля до обычной работы. Обновление существующей установки сохраняет установленный администратором пароль и не возвращает систему к bootstrap-состоянию. Точные первоначальные учётные данные указаны в [INSTALL.md](INSTALL.md).
