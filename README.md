# Control Center 0.28.0 Stable

Control Center — самостоятельная платформа управления инфраструктурой для администраторов. Этот репозиторий является официальным публичным Stable-каналом продукта.

## Текущая стабильная версия

**0.28.0** — текущая стабильная версия.

Основное изменение 0.28.0 — усиленная проверка актуальности сетевого verification evidence. Результат проверки связности теперь привязан к точному каноническому плану сетевого изменения и его ревизии, имеет ограниченный срок действия и повторно проверяется непосредственно перед переходом state machine к применению.

Старое, подменённое, относящееся к другой ревизии либо искусственно продлённое evidence отклоняется fail-closed. Verification не является самостоятельной авторизацией изменения сети.

## Аутентификация после чистой установки

Чистая установка создаёт локального пользователя `admin` с первоначальным паролем `admin`. При первом успешном входе пароль необходимо обязательно изменить; до смены пароля обычная работа запрещена. Обновление существующей установки сохраняет заданный администратором пароль и не сбрасывает его.
